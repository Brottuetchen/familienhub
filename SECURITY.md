# Security policy

Please report vulnerabilities **privately** via GitHub: *Security → Report a vulnerability* in this repository. Do not open a public issue.

Include what you found, how to reproduce it and which version (app version under *More → Send feedback*, server version under *Administration*). You will get an answer within a week.

Supported: the latest release and `main`. How the project handles security is described in [docs/security.md](docs/security.md).
