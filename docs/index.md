# Familienhub

**The self-hosted family hub that works on its own and plugs into what you already run.**

One app for what is on today: tasks, shopping, meals, events and reminders. It runs on your own server (one Docker container plus PostgreSQL), has real push notifications, Android widgets and an offline mode. If you already run Nextcloud, Home Assistant, Paperless or Mealie, the hub shows that data too and leaves it where it is.
